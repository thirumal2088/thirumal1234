This archive includes the published application source, built Worker,
database schema migrations, and the existing Sites deployment manifest.
Staff records, attendance, photos, advances, and voice notes are stored
in the live database. Credentials are configured in the hosted environment.

The app requires a Worker runtime, a D1 database bound as DB, the Sites
sign-in integration, and the RAINBOW_ADMIN_CREDENTIAL runtime secret.
GitHub can store the source. GitHub Pages alone cannot run this app.
